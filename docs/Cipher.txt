The Cipher class is responsible for deciphering encrypted text using a validated CipherKey object.

Responsibilities & requirements:

* Accept encrypted text and return the deciphered String.
* Use the character arrays stored in CipherKey to decipher each character.
* Find each encrypted character in the ciphered array and replace it with the original character at the corresponding index.
* Leave characters not included in the cipher unchanged.
* Do not directly access files or display output.

Class design:

Attributes:
    cipherKey: CipherKey
    - Stores the validated CipherKey object used for deciphering.

Methods:
    Cipher(cipherKey: CipherKey)
    - Initializes the Cipher using a validated CipherKey object.
    - Throws an IllegalArgumentException if the provided key is null.

    decipher(cipheredText: String): String
    - Iterates through each character in the encrypted text.
    - Searches for the character in the ciphered array.
    - Replaces it with the character at the same index in the original array.
    - Leaves characters not found in the ciphered array unchanged.
    - Returns the deciphered String.
    - Throws an IllegalArgumentException if the provided text is null.
