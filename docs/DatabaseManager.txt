class DatabaseManager // Zaid Al Falah

DatabaseManager:
- Queries SQL commands and returns data pulled from .tsv formatted datasets.
- Interfaces with java.sql pacakage
- All getters and setters pull from remote data, the class itself does not
  store any data from the tables. Think of it like a middle-man between the user
  and the requesitioned data

  Class design:
    Fields:
    - sqlURL : string
      Points to the database to process. Can be changed via setURL() or
      in the constructor. By default it points to jdbc:sqlite:data/mission_briefs.db
    - username : string
      Dummy username for use in connections
    - password : string
      Dummy password for use in connections

  Constructors: 
    DatabaseManager()
    - Creates a DatabaseManager with default database "data/mission_briefs.db"

    DatabaseManager(url : string)
    - Creates a DatabaseManager pointing to a specific database,
      specified by the String url parameter.

  Methods:
-- NOTE: All searches are case insensitive via LIKE queries
    + getColumn(url : string, column : string) : string[]
      Takes in a URL and column title and returns all data
      stored within that column.
    + getColumn(column : string) : string[]
      Overload which uses the current url pointed to in 
      sqlURL.
    + getRecords(url : string, column : string, key : string) : string[]
      Returns an String array of all matching records. Records are
      formatted as tab-separated values, which can be parsed out
      easily with a .split('\t') command. Takes in a String URL to the
      database (in which the DatabaseManager's current URL may be passed),
      a String column which contains the title of the column to match,
      and a String value which the query will search for.
    + getRecords(column : string, key : string) : string[]
      Overload for the previous function, when URL is not specified,
      the manager will use the URL it was instantiated with.
    + importTSV(path : string, dirOut : string, dbOutName : string) : Boolean
      Creates a database from a preexisting TSV file. Throws IOException.
