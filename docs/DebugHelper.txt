class DebugHelper // Zaid

DebugHelper is a 'static' class (i.e. has no instanced information) which is designed
to provide helper functions for the purposes of live-debugging the project.

Fields: -

Methods:

debugPrintln(obj : Object) : void
- Prints out message in System.out, but also includes the current method
  from which the method came from.

debugPrintarray(Object[] arr)
- Prints out the contents of an array line by line, indexed
