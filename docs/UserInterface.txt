Zaid Al Falah // UserInterface Class Description

Public UserInterface class will be used to manage all command-line arguments input by a user.

Responsibilities & Reqs:
- Handles and verifies user input, handles invalid input by
  throwing IllegalArgumentException.
- There is only one public method to this class, which is to
  run the interface. 
- All requisite UI logic is contained in runInterface
