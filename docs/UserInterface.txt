UserInterface Class Description

The UserInterface class is responsible for the interactive terminal interface shown after authentication has completed.

Homework 4 replaces the Homework 3 file-based command line interface with a menu that remains active until the user selects Exit.

Responsibilities & Requirements:
- Display the mission menu.
- Keep the interface running until Exit is selected.
- Allow the user to list available mission briefs.
- Display mission titles with corresponding numbers.
- Allow the user to select a mission by number.
- Display the title, date, and brief of the selected mission.
- Return to the menu after an operation is completed.
- Handle invalid menu input without terminating unexpectedly.
- Handle invalid mission numbers without terminating unexpectedly.
- Handle unavailable mission data gracefully.
- Do not execute SQL or directly access SQLite.
- Obtain mission information through DatabaseManager.
- Authentication occurs before UserInterface is started and is handled by Team Member B.
- Mission searching is Team Member C's responsibility and will be connected to the user interface through the team's final search component.

Class Design:

Attributes:

    databaseManager: DatabaseManager
    - Supplies mission records to UserInterface.
    - UserInterface does not execute SQL itself.

    scanner: Scanner
    - Reads terminal input from the user.

    output: PrintStream
    - Displays menus, missions, and messages.
    - Can be replaced during testing so output can be verified.

Constructors:

    UserInterface()
    - Creates an interface using the default DatabaseManager,
      System.in, and System.out.

    UserInterface(DatabaseManager databaseManager,
                  Scanner scanner,
                  PrintStream output)
    - Allows dependencies to be supplied.
    - Primarily supports unit and integration testing.

Methods:

    runInterface(): void
    - Starts the interactive menu loop.
    - Continues until the user selects Exit.

    runInterface(String[] args): void
    - Compatibility method used by the existing TopSecret class.
    - Starts the Homework 4 interactive interface.

    displayMenu(): void
    - Displays the available user-interface options.

    displayMissionList(): void
    - Retrieves mission titles through DatabaseManager.
    - Displays each title with a corresponding number.

    displayMission(int missionNumber): void
    - Displays the title, date, and brief for the selected mission.
    - Handles an invalid mission number without crashing.

Testing:

Unit tests use a fake DatabaseManager so UserInterface can be tested without SQLite.

Integration tests use a temporary SQLite database through the real DatabaseManager to verify that the user interface can display database-backed mission information.
