Planned Responsibilities:
- Display the interactive menu.
- List mission titles with corresponding numbers.
- Display a selected mission.
- Allow access to the search feature.
- Continue displaying the menu until Exit is selected.
- Handle invalid user input without terminating unexpectedly.
- Do not directly access SQLite.
- Do not perform authentication.

Planned Unit Tests:
- Interface starts without throwing an unexpected exception.
- Menu options are displayed.
- Mission titles are displayed as a numbered list.
- A valid mission number displays the requested mission.
- An invalid mission number is handled gracefully.
- Invalid menu input is handled gracefully.
- The menu is redisplayed after reading a mission.
- Selecting Exit ends the interface loop.

Planned Integration Tests:
- Successful authentication transfers control to UserInterface.
- Mission records supplied by the database layer can be displayed by UserInterface.
- Selecting a mission displays the correct database-backed record.
- Search results supplied by Team Member C can be displayed.
- Multiple actions can be performed during a single program session.

Note:
MissionAccess is a proposed interface name for planning purposes.
The final interface name and methods should be coordinated with the team before implementation.
