Relationships

TopSecret uses LaunchOptions to choose the terminal interface or WebServer.
WebServer creates an HttpServer and registers LoginHandler and PageHandler.
LoginHandler and PageHandler implement HttpHandler.
LoginHandler uses UserAccountManager to verify credentials and SessionManager to create sessions.
PageHandler uses SessionManager to check the cookie and AppController to build page text.
AgencyInterface (terminal) and PageHandler (web) both use AppController.
AppController uses BriefManager, AgentManager, FacilityManager, and AuditLogService (AuditLogManager).
AppController uses RecordType and returns text; the web view (Team C) wraps it in HTML.
SessionManager stores UserAccount objects in memory; no database table is added.
