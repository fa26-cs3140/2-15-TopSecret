The AgencyInterface class is responsible for the terminal menu shown after a user logs in.

Responsibilities & requirements:

* Let the user choose Briefs, Agents, or Facilities, then List, Read, or Add entries of that type.
* Prompt for each property when adding an entry; the new entry appears in the list immediately.
* Record READ and CREATE actions in the audit log.
* Let admins review the audit log. Add and Review audit log are hidden from standard users.
* Handle invalid input without crashing.
* Do not directly access SQLite; use AgencyDataService and AuditLogService.

Class design:

Attributes:
    data: AgencyDataService
    - Lists and adds briefs, agents, and facilities.

    auditLog: AuditLogService
    - Records and returns audit-log entries (implemented by AuditLogManager).

    currentUser: UserAccount
    - The logged-in user.

    scanner: Scanner / output: PrintStream
    - Terminal input and output.

Methods:
    AgencyInterface(data, auditLog, currentUser, scanner, output)
    - Throws an IllegalArgumentException if any argument is null.

    run(): void
    - Runs the main menu until Exit is selected.

    displayMainMenu(): void
    - Shows Briefs, Agents, Facilities, Review audit log (admin only), and Exit.

    displayTypeMenu(type: RecordType): void
    - Shows List, Read, Add (admin only), and Back.

    getCurrentUser(): UserAccount
    - Returns the logged-in user.

Supporting classes:
    RecordType - enum of BRIEF, AGENT, FACILITY.
    DatabaseManager - implements AgencyDataService; stores briefs, agents, and facilities in SQLite.
