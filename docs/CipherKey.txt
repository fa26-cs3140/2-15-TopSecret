The CipherKey class is responsible for validating and storing the character mappings used to decipher text.

Responsibilities & requirements:

* Accept the contents of the key file as a String.
* Validate that the key contains exactly two lines of equal length.
* Verify that the characters in each line are unique.
* Store the original and encrypted characters in separate arrays.
* Handle invalid keys without terminating the program.
* Do not directly access files.

Class design:

Attributes:
    original: char[]
    - Stores the original characters from the first line of the key.

    ciphered: char[]
    - Stores the encrypted characters from the second line of the key.

Methods:
    CipherKey(key: String)
    - Validates the provided key and initializes both character arrays.
    - Throws an IllegalArgumentException if the key is invalid.

    validateKey(key: String): boolean
    - Returns true if the key contains two lines of equal length with unique characters.
    - Returns false if the key is invalid.

    getOriginal(): char[]
    - Returns a copy of the original character array.

    getCiphered(): char[]
    - Returns a copy of the encrypted character array.
