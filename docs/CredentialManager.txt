CredentialManager is the interface implemented by UserAccountManager and the
legacy CredentialManagerLibrary.

It defines credentialsExist, isValidUsername, isValidPassword, verifyLogin,
createCredentials, and changePassword. The interface has no constructor.
The generated shared class diagram lists the exact signatures.

UserAccountManager is the current multiple-account implementation. It uses
SQLite for usernames and admin flags and separate ciphered credential files.
CredentialManagerLibrary remains the legacy file-based implementation.
