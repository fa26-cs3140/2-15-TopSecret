Interface for CredentialManagerLibrary. Serves no other purpose besides being implemented.

Methods:
• CredentialManagerLibrary(fileHandler: FileHandler, cipher: Cipher)
	• Saves the file handler and encryption helper for use.
• isValidUsername(username: String): boolean
	• Returns true if the username follows the rules, false if not.
• isValidPassword(password: String): boolean
	• Returns true if the password follows the safety rules, false if not.
• credentialsExist(): boolean
	• Returns true if a credential file is found in storage.
• verifyLogin(user: String, pass: String): boolean
	• Reads, decrypts, and returns true if the login details match.
• createCredentials(user: String, pass: String): boolean
	• Encrypts and saves a brand-new username and password pair.
• changePassword(user: String, pass: String): boolean
	• Encrypts and saves an updated password for the user.
